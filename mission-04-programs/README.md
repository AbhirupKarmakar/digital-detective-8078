## Task 4.2 — Compare a compiler and an interpreter

| Point | Compiler | Interpreter |
|---|---|---|
| When it works | Translates the program before it runs. | Reads and runs the instructions while the program runs. |
| Typical output | Often makes a separate executable file. | Usually runs the code without making a separate executable first. |
| Example | C compiler | Python interpreter |
| One advantage | The finished program can run quickly. | It is convenient to try and change code. |

A compiler translates a program before it runs and often makes an executable file. An interpreter reads and runs instructions while the program is running. Compiled programs can run quickly, while interpreted programs are convenient to test and change. Some languages use a mix of both approaches.
